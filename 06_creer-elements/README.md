# Devoir : Créer des éléments HTML avec JavaScript

1. Concevez un programme qui affiche dynamiquement l'heure courante sur
   une page Web. Par exemple, si la page Web est consultée à 14:40:00,
   elle affiche 14:40:00, tandis que si elle est consultée à 20:05:10,
   elle affiche 20:05:10.

2. Modifiez ensuite votre code de sorte à ce que l'affichage soit mis à
   jour automatiquement à chaque seconde. Pour ce faire, vous aurez
   besoin de la fonction d'ordre supérieur [setInterval].

3. Enfin, faites en sorte que l'heure soit affichée noir sur blanc
   pendant le jour, et blanc sur noir pendant la nuit.

[setInterval]: https://developer.mozilla.org/en-US/docs/Web/API/Window/setInterval
