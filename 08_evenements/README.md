# Devoir : Événements

Concevez une page Web qui permet à deux personnes de jouer une partie de
[tic-tac-toe]. Une partie de tic-tac-toe se termine lorsqu'une ligne,
une colonne ou une diagonale de la grille est entièrement remplie d'un
même symbole, ou lorsque toutes les cases de la grille sont remplies. Si
les cases sont numérotées de 0 à 8, de gauche à droite et de haut en
bas, les combinaisons gagnantes sont les suivantes :

```
[0, 1, 2]
[3, 4, 5]
[6, 7, 8]
[0, 3, 6]
[1, 4, 7]
[2, 5, 8]
[0, 4, 8]
[2, 4, 6]
```

[tic-tac-toe]: https://fr.wikipedia.org/wiki/Tic-tac-toe
